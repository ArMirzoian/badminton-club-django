- ✅ Регистрация и авторизация игроков
- ✅ Автоматическое открытие/закрытие записи (расписание)

- ⚡ Быстрая загрузка (< 2 сек)

## 📊 Структура базы данных

### Таблица: users
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    password_hash TEXT NOT NULL,
    telegram_id INTEGER,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Таблица: campaigns
```sql
CREATE TABLE campaigns (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    game_date DATE NOT NULL,
    status TEXT DEFAULT 'open',  -- open, closed
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    closed_at TIMESTAMP
);
```

### Таблица: votes
```sql
CREATE TABLE votes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    campaign_id INTEGER NOT NULL,
    vote TEXT NOT NULL,  -- 'yes', 'no'
    position TEXT,  -- 'main', 'reserve', 'declined'
    voted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (campaign_id) REFERENCES campaigns(id),
    UNIQUE(user_id, campaign_id)
);
```

### Таблица: statistics (копия для совместимости с Google Sheets)
```sql
CREATE TABLE statistics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    game_date DATE NOT NULL,
    group_name TEXT,  -- 'основа', 'резерв', 'отказ'
    name TEXT,
    telegram_id INTEGER,
    timestamp TIMESTAMP
);
```
